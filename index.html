Marca do sistema

Use uma URL pública HTTP ou HTTPS. A imagem precisa de internet e não é incluída no cache offline. Deixe vazio para remover.

Aparência

Cores em hexadecimal: #145a48. Contraste do texto automático.

Aparência da tela. Impressão em preto e branco.

Padrões para novos contratos

Usados por modelos sem revisões próprias. Os intervalos são somados ao odômetro; contratos já salvos não são alterados.

Instalar aplicativo

A abertura direta do HTML continua disponível. Para instalar, acesse a versão publicada em HTTPS.

A instalação é opcional. Os dados continuam neste navegador; use o backup para transferi-los.

Gravação automática em JSON

Autorize uma pasta principal e outra para cópia. Pode escolher a pasta do HTML. Pastas protegidas do sistema podem ser bloqueadas pelo navegador.

Arquivo: contrato-facil-banco-v1.json. Aguarde a gravação antes de fechar. Os arquivos acompanham exclusões; exporte backups históricos antes de alterações importantes.

Backup dos dados

O backup inclui modelos, contratos, peças e preferências. Guarde o arquivo em um local seguro: ele contém os dados dos clientes.

Restaurar um backup substitui os dados deste navegador após sua confirmação.
