Aparência

Escolha as duas cores ou digite # e seis caracteres hexadecimais (ex.: #145a48). O texto se adapta para manter o contraste.

As cores e o espaçamento alteram a tela. Os contratos continuam em preto e branco, prontos para impressão.

Padrões para novos contratos

Usados por modelos sem revisões próprias. Os intervalos são somados ao odômetro; contratos já salvos não são alterados.

Backup dos dados

O backup inclui modelos, contratos e preferências. Guarde o arquivo em um local seguro: ele contém os dados dos clientes.

Restaurar um backup substitui os dados deste navegador após sua confirmação.
